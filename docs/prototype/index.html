本期原型覆盖的全局交互

通知中心与红点

铃铛打开最小通知列表，未读红点驱动角标；点击单条通知跳转对应页面并置为已读。FA 端风险导航项显示未复核数量。

AI 对话与预置 Prompt

两端 AI 助手支持快捷提示词、关键词路由回复与跨页面预填问题；对话记录在会话内保留，页面底部固定免责声明。

审核链路与留痕提示

方案、报告、审批均保留"AI 草案 → 规则校验 → 人工复核 → 合规审批 → 留痕执行"状态，关键操作仅更新演示状态。
