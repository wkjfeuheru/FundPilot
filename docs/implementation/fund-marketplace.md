# 用户端基金超市实施记录

## 范围与计划（2026-11-16）

依据 CLAUDE.md、docs/design 全部设计文档与 investor/funds.html 原型。用户确认本次完成基金浏览、详情、净值、自选；申购入口提示交易模块待接入，不实现资金冻结、交易或 TA 确认。AI 入口展示待接入状态，不生成虚构分析。

1. 先验证天天基金公开页面与历史净值响应，保存原始快照、来源 URL、采集时间及 SHA-256；选择覆盖四大类的少量基金。缺失必填事实时拒绝该基金导入，不填造数据。
2. 建立六个 FUND 接口的 MySQL / Redis 集成测试及前端行为测试，观察现有空页/缺失接口失败，再实现分层查询、自选隔离与 CSRF、历史曲线、风险指标。
3. 页面沿用原型标题、适当性提示、筛选工具栏、三列基金卡片与详情抽屉。搜索/类型/自选/详情/曲线区间放 URL；具备加载、空、失败重试、写入反馈及窄屏布局。
4. 提供可重复的低频采集与 SQL 导入脚本；使用现有 fund/fund_nav/fund_dividend 表，不修改 schema。净值与分红仅追加，重复导入不改历史，冲突拒绝；不自动授予池内评级。
5. 导入现有独立验收库 tougu_auth_validation_20261116，保留双端演示账号；执行前后端全套测试、生产构建、浏览器交互与响应式验收，记录来源覆盖与限制。

## 实现口径

- 货币基金展示七日年化与每万份收益，不以单位净值 1.0000 或近一年收益 0 冒充投资表现。
- 风险指标按设计计算近一年未复权单位净值；明确分红会影响该指标。日收益率使用样本标准差，最大回撤按负百分数输出。数据不足返回空值并解释，不显示虚假的零波动。
- 曲线最多 250 点；超出时按时间顺序等距抽样并保留首尾，风险指标仍使用完整窗口。默认窗口以最新已披露净值日为锚点，明确显示数据截止日。
- 风险等级采用已记录的来源文字到系统 R1–R5 映射；四大类为系统映射，保留官方细分类。单值赎回费无法代表全部阶梯，固定选择明确持有期档并在来源记录及页面说明。
- 本次不新增公开数据导入 API；采集、校验、生成 SQL 与手工导入分离。数据仅用于演示，不改变现有用户资金与持仓。

在项目根目录执行：

```powershell
# 已有快照离线校验并重新生成 SQL（不访问网络、不写库）
python scripts/import_eastmoney.py --output docs/data/funds/20261116 --offline

# 明确指定目标库，验证来源和 SQL 一致后写入；需已有 MySQL 容器及表
python scripts/apply_fund_snapshot.py --snapshot docs/data/funds/20261116 --database tougu_auth_validation_20261116

# 日后重新采集须使用新目录及所需起始日期，保留本次验收快照
python scripts/import_eastmoney.py --output docs/data/funds/新批次日期 --start YYYY-MM-DD
```

导入以整个批次为事务；历史净值/分红仅追加，遇同日期不同数值即拒绝并回滚。已在真实 MySQL 验证重复执行不新增、冲突后包含基金名称更新在内的全部写入回滚。`apply_fund_snapshot.py` 使用本机 `tougu-mysql` 容器已有凭据，不输出密码；不可使用 MySQL `--force` 绕过遇错退出。
