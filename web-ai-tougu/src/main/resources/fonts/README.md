# 资产报告中文字体

`NotoSansSC-Regular.ttf` 来自 Noto CJK 项目的简体中文可变 TrueType 字体，使用 fontTools 将 `wght=400` 固定为静态实例，供 PDFBox 以子集方式嵌入 PDF。

- 来源：https://github.com/notofonts/noto-cjk/blob/main/Sans/Variable/TTF/Subset/NotoSansSC-VF.ttf
- 许可证：随包 `OFL.txt`（SIL Open Font License 1.1）。
- 报告不依赖部署环境的系统字体；生成 PDF 时仅嵌入用到的字形。
- 不在运行时下载字体或调用外部渲染服务。
